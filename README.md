# Zotero Word Macros

A collection of Microsoft Word VBA macros for working with Zotero citations and references.

## Features

* **Citation coloring** — Apply colors to Zotero citations in Microsoft Word.
* **IEEE reference coloring** — Format or color IEEE-style references for easier identification.
* **Zotero citation links** — Add clickable links between citations in Word and their corresponding Zotero items.
* **Citation management utilities** — Additional VBA tools for working with Zotero-generated citations.

## Included Macros

| Macro                     | Description                                                |
| ------------------------- | ---------------------------------------------------------- |
| `CitingColor.bas`         | Color Zotero citations in Microsoft Word                   |
| `ColorIEEERefs.bas`       | Color IEEE-style references                                |
| `ZoteroLinkCitation.bas`  | Add links to Zotero citations                              |
| `ZoteroLinkCitation2.bas` | Alternative/extended Zotero citation linking functionality |

## Requirements

* Microsoft Word
* Zotero
* Zotero Word Integration
* VBA macros enabled in Microsoft Word

## Installation

1. Download the `.bas` file(s) you want to use.
2. Open Microsoft Word.
3. Press `Alt + F11` to open the **Visual Basic for Applications** editor.
4. Import the `.bas` file using **File → Import File...**
5. Run the corresponding macro from Word.

> **Note:** These macros are intended to work with Zotero-generated citations in Microsoft Word. Their behavior may depend on the Zotero citation format and Microsoft Word version.
